# Показ проекта клиенту — 2–3 минуты

1. **Стартовая страница** (`/#welcome`). Покажите позиционирование: «Ваши клиенты не любят ждать». Нажмите «Посмотреть демо».
2. **Обзор**. Кратко покажите диалоги, долю решений, скорость ответа и оценку сэкономленного времени. Смените период с 7 на 30 дней: цифры и график действительно меняются. Экспортируйте CSV.
3. **База знаний**. Покажите PDF, FAQ и URL в одном списке. Добавьте FAQ «Сборка мебели» с ответом «Сборка мебели стоит 1700 рублей. Мастер приезжает по субботам».
4. **AI-ассистент**. Спросите: «Сколько стоит сборка мебели?» Ассистент вернёт новую информацию и укажет источник.
5. **Telegram-сценарий**. Нажмите «Сколько стоит доставка?», затем «Хочу оформить заказ». Покажите ответ и карточку созданной заявки. Объясните, что это безопасный симулятор, а реальный канал подключается в настройках.
6. **История**. Откройте новый диалог, покажите полный контекст, источники и статус «Менеджеру». Нажмите «Решено»: появится отдельный статус решения командой.
7. **Настройки**. Покажите тон ответов, приветствие и подключение Telegram. Завершите на обзоре.

Для записи экрана удобно использовать браузер 1440×1000 или 1920×1080, масштаб 100%. Графики поддерживают hover-подсказки. Статистические карточки используют реальные записи демонстрационной базы; клиентские персональные данные и секреты не нужны.

При показе не называйте лексический поиск генеративной моделью: без ключа включён локальный RAG, с ключом — LLM с контекстом компании. Это полезный коммерческий аргумент: продукт демонстрируется без расхода API и легко подключается к провайдеру клиента.
