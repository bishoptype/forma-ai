## Что требует реальных подключений

Фактическая доставка сообщений через Telegram и генерация ответов внешним LLM не выполнялись: пользовательские API-ключи не предоставлены. Telegram pipeline проверен с mock API, локальный RAG — с настоящим хранилищем. PostgreSQL-конфигурация подготовлена, интеграционные тесты в этом окружении используют SQLite.

В pytest есть предупреждение о deprecated alias `anyio.abc.BlockingPortal` внутри стороннего Starlette TestClient. На результат тестов и выполнение приложения оно не влияет.
