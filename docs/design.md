# Forma AI — visual direction

Product: a calm, approachable support workspace for small retail teams.
User interface: Russian. Main showcase: dashboard; marketing page: #welcome.

The ui-ux-pro-max search for customer support SaaS analytics informed the light SaaS layout, restrained depth, clearly separated cards, consistent iconography and focus states. The final direction adapts its blue SaaS suggestion to a lavender identity suited to the product's quieter tone.

- Manrope 400–800, local system sans fallback; loaded from Google Fonts.
- Brand #7860ca; ink #30303c; canvas #f8f9fc; white cards.
- Lavender for AI, mint for resolved, amber for escalation.
- 236px desktop navigation, 34px content gutters, 10px card radius.
- Lucide icons, CSS geometric logo, vector area chart with tooltips.
- Breakpoints 600 / 800 / 1050 / 1250 / 1600px; mobile slide-out navigation.
- Native form inputs, accessible control names, native modal dialogs and reduced-motion support.
- Demo is clearly marked. No invented customer logos, testimonials or paying-customer claims.

No external image assets are required. The portfolio presentation focuses on the product itself.
