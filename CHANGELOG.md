# История версий

## v1.0.0

Первый релиз Forma AI для портфолио.

- Дашборд поддержки, история диалогов, выгрузка CSV и настройки компании.
- База знаний с импортом PDF, FAQ и HTTPS-страниц. Локальный поиск по источникам и опциональное подключение LLM.
- Telegram-симулятор с заявками и опциональное подключение реального бота через webhook.
- Запуск на Windows с SQLite и через Docker Compose с PostgreSQL.
